# Sales Report Automation

## Project Overview

Python application for automated Excel sales reports,
including data validation, dynamic formulas, formatting,
filters and automated software testing.

## Technologies

- Python
- OpenPyXL
- Pytest
- Microsoft Excel
- Git and GitHub

## Features

- Automated Excel report generation
- Product registration
- Automatic sales calculations
- Dynamic spreadsheet ranges
- Currency formatting
- Tables and filters
- Quantity and price validation
- Automated software testing

## Installation

```bash
pip install -r requirements.txt
```

## Running the Project

```bash
python relatorio.py
```

## Running Tests

Generate the report before running the tests.

```bash
python -m pytest -v
```
